# Image provenance

`mga-menu-unlocked.jpg` is an owner-supplied hardware photograph of the tested
`LS32CG552EUXUF` displaying the unlocked MGA page.

Before publication, the copy in this repository was:

- auto-oriented;
- resized from `5712x4284` to `1800x1350`;
- recompressed as JPEG for web delivery;
- stripped of all EXIF, GPS, phone-model, timestamp, and other metadata.

No menu content was added, removed, blurred, or otherwise altered.
